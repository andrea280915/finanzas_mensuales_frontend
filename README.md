# MiControl - Gestor de Finanzas Personales y Ahorro Progresivo

Proyecto web construido en **React + Vite**, estilizado con **Tailwind CSS** e integrado con gráficos interactivos usando **Recharts**.

## 🚀 Pasos para ejecutar en VS Code

1. Abre esta carpeta descomprimida en VS Code.
2. Abre la terminal (`Ctrl + ~` o `Cmd + ~`).
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre el enlace local indicado en la terminal (ej. `http://localhost:5173`).
